使い方と設計 / Guide & design

MusicXML の符号化された時間を、正確な分数と元の XML で確認する道具です。楽曲の正しさや MusicXML 全体の妥当性は判定しません。

Inspect encoded MusicXML timing with exact fractions and source witnesses. This is not a musical-correctness or full MusicXML-validity verdict.

1. 開く / Open

UTF-8 の .musicxml / .xml / .mxl（8 MiB まで）を開くか、オリジナルの合成デモを使います。ファイルは送信・自動保存されません。

Open a UTF-8 .musicxml, .xml or .mxl file up to 8 MiB, or try the original synthetic demos. Files are neither uploaded nor automatically saved.

2. 比較する / Compare

単位は四分音符 = 1。拍子の長さ、最大到達位置、終了カーソルは別々に表示します。声部を合算せず、連符比率を二重に適用しません。小節ラベルが重複しても #順番 で区別できます。

Quarter note = 1. Meter length, maximum extent and final cursor are separate. Voices are never summed and tuplet ratios are never applied twice. Ordinals disambiguate repeated measure labels.

3. 根拠を渡す / Share evidence

イベントを展開すると duration / divisions と XML 断片を確認できます。JSON と日英 HTML レポートには全小節、入力 SHA-256、展開後 XML SHA-256、エンジン版、制限が含まれます。HTML を保存してブラウザで開けば印刷できます。この画面の印刷は選択中の小節のみです。

Expand events to inspect duration / divisions and XML fragments. JSON and bilingual HTML include all measures, original/extracted SHA-256, engine version and limits. Open the saved HTML to print every measure. Direct screen printing includes only the selected measure.

境界 / Boundaries

途中の divisions / 拍子変更は保留し、次の明示的な境界設定まで不明状態を継承します。段別拍子・自由拍子・交換拍子も未対応です。弱起などの implicit 小節と non-controlling 小節では通常の長さ比較を省略します。浄書・再生・OCR・修復・XSD 全検証・音高やタイ・反復展開・演奏タイミングは対象外です。

Mid-measure divisions / meter changes stay unresolved until explicit supported boundary resets. Staff-specific, unmeasured and interchangeable meters are unsupported. Implicit and non-controlling measures skip ordinary extent comparison. No engraving, playback, OCR, repair, full XSD validation, pitch/tie verification, repeat expansion or performance timing.

安全性 / Safety

XML は深さ 64・180,000 要素、スコアは 64 パート・4,000 小節・20,000 イベント（1 小節 1,000）。MXL は 128 エントリ・展開宣言合計 24 MiB、展開倍率 200。XML 断片は 1,200 文字までで省略を明示します。外部 DTD は解決せず、内部実体や危険・重複 ZIP パスを拒否します。

XML: depth 64, 180,000 nodes. Score: 64 parts, 4,000 measures, 20,000 events, 1,000 per measure. MXL: 128 entries, 24 MiB declared total, inflation ratio 200. Fragments are capped at 1,200 characters with truncation disclosed. External DTDs remain inert; internal entities and unsafe/duplicate ZIP paths are rejected.

追加の上限：拍子 32 組・加算 64 項・1 組のテキスト 4,096 文字・拍子分数 128 桁。小節内要素 2,000、指摘は小節あたり 256・全体 12,000。識別子はパート ID 128、名前 256、小節ラベル 128、声部・段 64 文字です。超過は明示して保留・拒否し、識別子を切り詰めません。

Additional limits: 32 meter pairs, 64 additive terms, 4,096 text characters per pair, 128-digit meter fractions. At most 2,000 measure children, 256 findings per measure and 12,000 total. Identity limits: part ID 128, name 256, measure label 128, voice/staff 64 characters. Excess complexity is explicitly unsupported or rejected; identities are not silently truncated.

プライバシー / Privacy

ページを読み込んだ後のオフライン読み込み・検査・保存に対応する設計です。オフライン再読み込みは対象外。読み込み中止は Worker を終了し、以前の結果を保ちます。ページを閉じるとデータは消えます。

Designed for offline import, inspection and export after the app has loaded, but not offline page reload. Cancelling terminates the worker and keeps the previous result. Closing the page discards imported data.
